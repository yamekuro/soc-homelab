# telemetry/

Agents, auditing, sensors and data contracts.

## First deployed source

The central Wazuh stack and one Debian bastion agent are deployed. The [first-agent validation](../docs/wazuh-first-agent-validation.md) records a journal-to-dashboard event, orderly lifecycle alerts, a controlled network interruption, reconnection, fresh delivery and cleanup.

Additional agents, endpoint auditing, firewall syslog, data contracts, reusable fixtures, retention and broader source-health checks remain open. Full logs and operating addresses stay in private evidence. See the [P1 readiness checklist](../infra/p1-preflight.md) and [blueprint](https://yamekuro.github.io/soc-homelab/blueprint.html).
