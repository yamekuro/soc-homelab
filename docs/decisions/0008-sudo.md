# 0008 · Auditable privileged administration

Status: accepted design. Use individual administrative accounts and an auditable privilege-escalation mechanism rather than routinely sharing unrestricted root sessions.

The decision separates authenticated access, authorization to elevate, command logging, log transport and recovery access. Successful elevation alone does not prove that its events reach the SOC. Privilege changes that could remove the last recovery route require a tested alternative and explicit verification of the logging dependency.

The original account names, relationships between passwords, current root-recovery posture, secret locations and console procedures remain in the private record. The public edition makes no claim that root has been locked or that Wazuh ingestion is already operational.

The [P1 checklist](../../infra/p1-preflight.md) retains agent and ingestion gates. Public SSH configuration files are examples, not readbacks of the deployed bastion.
